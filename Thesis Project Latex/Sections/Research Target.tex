This project focuses on the ontological (in)security of Bosnia and how political speeches impact a state's identity. Under the framework set forth by Mitzen \parencite*[][p. 344]{mitzenOntologicalSecurityWorld2006}, states are inclined to seek ontological security, which requires a collective identity that constitutes a state identity. This is identity is shaped both internally and externally, but the aim of this research is to understand how the political speeches of Bosnia's politicians shape the identity of the Bosnian state and whether this strengthens or weakens the state's ontological security. The working hypothesis for this project are as follows:

\begin{description}
    \item $H_1$: There are unified concepts used by politicians in their speeches, regardless of party, that shape the Bosnian state identity.
    \item $H_2$: Ontological security shapes the political discourse amongst politicians.
\end{description}
